# Try out Unity Build

- STATUS: OPEN
- PRIORITY: 100
- TAGS: general

Create a new branch and try to get rid of the Makefile by instead compiling the project using unity build (basically
include all the .c files in one file and complile that one file with one command). This build method is considered
preferable in the modern world, stating that separate build units just complicate things and are more efficient only
on big projects as far as I can see.
